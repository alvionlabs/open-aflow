Key features

  • Install without admin rights, and open Pod Board from the Start menu.
  • See what’s missing. The setup check names a tool it can’t find, with an install link, a path field, and Recheck.
  • Close the window and keep working. The app stays in the tray, and the tray dot shows when something needs you.
  • Get a toast for a new blocked, merge, or reply item. A click opens that run.
  • Quit without losing a run. A resumed claude keeps running through Quit, a crash, and an update.
  • Get updates after a yes. The app downloads a release, then asks: Restart now or Later.

Electron includes Node. The backend stays Node.
Instead of
Tauri, which adds Rust and a separately built server.
Result

Who

Friends first, under MIT

Why
“I will let my friends do this first and then go public later.”
Instead of
Staying with one user, or all rights reserved.
Result
Signing and a public launch become the next plan.

Quit never kills a resumed run

Why
The board starts claude runs detached on purpose.
Instead of
A process-tree kill or a Job Object, which the research suggested.
Result
The only kill is the server’s own process, after 80 s. The drain cap is 70 s.
Who
agent flagged in the overview; the human then wrote “everything looks good to me”.

Unsigned, with the update signature check off

Why
Friends won’t rebuild, and an unsigned build needs the check off.
Instead of
Signing now.
Result
The GitHub account is the trust boundary, and SmartScreen warns friends.
Who
agent plan default

Server in utilityProcess, stopped by message

Why
A server crash spares the window. A kill on Windows is abrupt.
Instead of
The main process; a signal.
Result
One restart, then an error box. execPath is Electron’s exe, so slice R1 removed that fallback.
Who
agent plan default

Token in memory in production

Why
A written file would break a pnpm dev page on the same config folder.
Instead of
The dev token file.
Result
Any local process can read it from GET / (queue, before hosting).
Who
agent plan default
