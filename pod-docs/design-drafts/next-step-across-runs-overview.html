Next step across runs

Goal: when another run needs you more urgently than the run you're looking at, screen 1 says so in one line at the top of the main column, with a button that opens that run. When nothing outranks the selected run, the page looks exactly as it does today.

One sprint, urgent-banner. The model and the server don't change. Plan: pod-docs/plans/next-step-across-runs.md. Look: next-step-across-runs-look.html (B picked).
