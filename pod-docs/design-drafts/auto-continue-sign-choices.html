Auto-continue: how a run shows it

When Auto-continue is on, OpenAFlow sends continue to the run by itself. Today the only sign is a mono auto pill on the sidebar card. You want a better sign, and one in the main run view too. Drawn in the app's dark theme.

1. The sign on the sidebar card

It sits after the status. It only shows while Auto-continue is on.

a. Mono pill now

A code-style pill. Reads like a label from the code, not a state.
