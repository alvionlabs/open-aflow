Next step across runs: where should it go?

The board's look stays the same. Only the place of one new element changes. The new element has a dashed blue outline in these pictures, and it has no outline in the real board.

Today you only see this from the red dot in the sidebar. The new element points you to it. A click on it selects that run.

In all three: the element shows only when another run has something more urgent than the selected run's card (blocked beats merge, merge beats reply, reply beats a pending decision). When nothing outranks the selected run, the page looks exactly like "Today". It has no Answer or Merge button of its own. A click selects that run, and that run's card holds the action.
