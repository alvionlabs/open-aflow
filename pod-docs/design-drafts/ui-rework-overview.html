UI rework — how it fits together

Goal: make the run screen say what just happened and what comes next, so that Merge, then Continue, then pod running reads as one flow. Fix the install-test defects, use the Windows folder dialog for Add repo, and let a leftover run be removed. One sprint, before v0.1.0. Plan: pod-docs/plans/ui-rework.md. Main flow: you merge a PR, then press Continue

sequenceDiagram
  actor You
  participant Card as Next step card
  participant Server
  participant Pod as pod session
  You->>Card: Merge, then confirm
  Card->>Server: merge
  Server-->>Card: merged
  Card->>Card: merge panel closes, list shows "Merged PR #35;12 · 12:03", "Continue — now"
  You->>Card: Continue
  Card->>Card: button reads Sending…
  Card->>Server: resume continue
  Server->>Pod: continue
  Server-->>Card: sent
  Card->>Card: list adds "Sent continue · 12:04", "pod runs — now"
  Server-->>Card: next Board: run reads running

Data

No new stored data. The “what happened” list lives in the card's state for the current stop. A run's last activity is computed when the Board is built, from the newest agent write, queue entry change, or PR event. Forget deletes one claim file and adds a forget-run line to actions.jsonl.

Out of scope

  • Delete or Clean up a leftover run's worktree and branch
  • The full run-screen redesign, with the terminal host's Terminal tab
  • The other run-state known issues
  • Linux and macOS folder dialogs (not tested in this plan)
