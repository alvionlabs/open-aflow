Gaps and angles

Angles disagree: regret about Tauri

Part 1 found no maintainer's regret. Part 2 found Paseo's: the sidecar "became its own project" and "I was building Electron with extra steps". Windows was not where Tauri hurt. Paseo

Angles disagree: orphan sidecars

Part 1 reports orphans on exit. Part 4 read the plugin source: it calls child.kill() on stored children at exit, but one PID, not the tree, and not on a crash. write-up, lib.rs, tauri#1896

  • Size win is uncertain. Tauri about 2.5 MB vs Electron about 85 MB on one Windows 11 app (blog). A 2022 Windows 10 test (possibly stale) had Tauri larger. A sidecar adds tens of MB (own inference). issue 5889, issue 15134
  • Crash cleanup. A force-killed Tauri host left Node running and broke the next build. Fix: Job Object plus parent-PID poll. Dormouse PR 41, MouseTerm PR 32
  • Electron exit. utilityProcess docs are silent on exit cleanup. will-quit does not fire on Windows shutdown. app API
  • Console flashes. windowsHide defaults to false. child_process
  • .cmd shims. Need shell: true since April 2024 (stale date, still in force). advisory
  • PATH. A child inherits the parent's environment; a Start-menu app may see a stale PATH (inference). Microsoft
  • Hono static root is relative to cwd. Hono
  • pnpm. Junctions dangled; hoisted fixed it for about 135 MB; electron-builder 26.3.1 broke hoisted. PR 54, issue 9580
  • Updates unsigned. electron-updater on master rejects unsigned updates unless opted out. Tauri updater needs its own key. NsisUpdater.ts, Tauri updater
  • Linux next. Tauri: "Linux does not emit tray icon events". WebKitGTK is the most-reported weak point. tray

Best practices

  • Kill the tree: taskkill /pid N /t /f. taskkill
  • For crashes, use a Job Object with kill-on-close. Job Objects
  • windowsHide: true on every spawn. Effect PR 7154
  • Spawn real .exe files with argument arrays. child_process
  • Bundle the server to one file with esbuild. Anchor the static root. esbuild
  • Serve from 127.0.0.1. Tauri guide
  • Per-user NSIS installs need no admin. Tauri, electron-builder
  • In CI, fail if the installer shrinks or the app does not start. issue 9580
  • Measure on your own machine. issue 5889

Ideas, minimal to bold

1. Harden the server, one-port mode. windowsHide, .cmd handling, parent-PID self-exit, serveStatic. No shell.
2. Zip plus Start-menu shortcut. No installer, no signing. Test notifications first.
3. Electron shell forks the bundled server. Load 127.0.0.1; use extraResources.
4. Shared tree-kill helper. taskkill /t /f, PID file, orphan sweep at next start.
5. Tool resolver. Find git, gh, claude; merge registry Path; settings override; "tool not found" screen.
6. Tray-first mode. Close hides; server keeps running; tray has Open and Quit.
7. Two-day spike. Electron vs Tauri + SEA; compare size, RAM, exit cleanup.
8. Signed, auto-updating installer for outside users (Artifact Signing or Store MSIX).
