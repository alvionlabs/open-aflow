# Idea: Urgent banner on other screens

Status: parked

## The idea
Show the urgent banner from plan `next-step-across-runs` on the wave board (`/board`) and the engineer view too, not only on screen 1, so an urgent item in another run is seen from any screen.

## Why it's on hold
Plan `next-step-across-runs` keeps the banner to screen 1 to stay small; the wave board and engineer view are deep-dive screens you visit briefly.

## What would make it worth building
You spend long stretches on the wave board or an engineer view and miss a blocked run while you're there.
